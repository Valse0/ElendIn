## [0.2.0-beta.1] — 2026-11-08 — Public Beta 1

### Fixed & Improved
- **Analysis Engine Accuracy**:
  - Eliminated critical false negatives on Professional CV: recognized TypeScript, React, REST API integrations, Figma, Git, GitHub, English B1, Vitest/React Testing Library, Vite, WCAG.
  - Corrected distinctions: "REST API integrations" is recognized as explicit REST API evidence, while standalone "API" is treated as related/partial evidence (never false full match).
  - Vitest and React Testing Library are classified as related testing technologies to Jest (giving partial credit), not falsely identified as identical.
  - English CEFR level extraction in job listings (e.g. `meta: 'english:b1'`) matches B1+ as full match, while "Intermediate English" is marked as related/partial evidence without false negative or false certainty.
  - Section parser broadened to recognize compound headers ("Skills & Tools", "Work History", "Education & Training", "Language", "Projects & Portfolio").
  - Date parser updated to handle standalone years (e.g. `2022`) as valid ranges without falsely triggering missing dates warnings.
  - Redaction preserved domain context for profile links (`github.com/[profile]`, `linkedin.com/[profile]`) to ensure evidence recognition without privacy leaks.
  - Matcher prioritizes body/experience/skills lines over contact headers for evidence snippets.
- **Mobile UI & Responsive**:
  - Fixed mobile hero headline overlap for "CV’N SANDIĞIN KADAR GÜÇLÜ DEĞİL." by adjusting font size clamp (`clamp(34px, 8.5vw, 104px)`), line-height (1.12), and inline-block strike styling to prevent clipping and line collision on narrow viewports.
- **Verification & Testing**:
  - Added regression test suites for Professional CV, Amateur CV, and precise distinction matching in `tests/engine.test.ts`.
  - Verified full test suite (79/79 tests passing) and production Vite build with TypeScript typechecking.

## [0.1.0] — 2026-11-07 — first complete source drop

### Added
- Rule-based analysis engine (no AI, no network): job-listing parser, CV parser, date/gap analysis, own skill matcher
  (found / alias / related / fuzzy / missing), severity engine, explainable scoring with a central config.
- Inspectors: **ATS Inspector** and **Copy-Paste Detector** active (18 finding types). HR Reviewer, Manager Murat,
  Security Officer and The Benchmarker are registered as planned inspectors and can be enabled without redesign.
- PDF text extraction with pdf.js, geometry-based column and reading-order detection, scanned / blank / encrypted /
  invalid file handling.
- Interface in Turkish, English and Spanish (separate cliché dictionaries per language), investigative-report results
  screen with stamp, score meter, requirement table and Before/After templates.
- Privacy-safe 1080×1350 PNG share card and PDF report export (subsetted DejaVu Sans so Turkish letters render).
- Web Worker analysis with main-thread fallback, 30 s timeout, cancel and reset.
- PWA: manifest, icons (generated by `scripts/make_icons.py`), app-shell service worker.
- Capacitor 7 Android wrapper configuration and GitHub Actions workflows (`ci.yml`, `android-apk.yml`).
- Tests: 76 Node tests (engine, i18n, real pdf.js extraction, schemas, PDF composer, meta checks).
